# ℹ️ About this application

## ValuSafe — inventory of valuables

A web application for recording valuables in a structured way: photos, purchase prices,
serial numbers, locations and insurance assignment — to run yourself on your
own web space.

The version running here is shown on the sign-in screen and in the changelog.

## Origins

The project started as a personal solution for recording valuables in a structured way
and grew over several months into a complete web application with
multiple users, security features and export options.

---

## Technology

- **Backend:** PHP 8.2 or newer, MySQL via PDO
- **Frontend:** HTML5, CSS3, JavaScript — no framework
- **PWA:** can be installed on iOS and Android
- All libraries and fonts are bundled; the application does not load
  anything from third-party servers at runtime
